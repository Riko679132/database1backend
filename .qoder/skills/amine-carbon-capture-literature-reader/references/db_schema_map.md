# Database Schema Map

This file maps the reading output to the existing project schema. It is a reference only: **do not modify `scripts/schema.sql`, existing fields, or `data/ccus.sqlite`.**

## Tables

### `compound`

| Field | Meaning | Source in reading |
|---|---|---|
| `compound_id` | PK | assigned by DB |
| `inchikey` | structure identity | resolve from CAS/name; never hand-type |
| `cas_no` | CAS registry number | paper/whitelist |
| `smiles` | structure | resolve from CAS/InChIKey; verify formula/MW |
| `standard_name` | canonical name | whitelist |
| `amine_class` | primary/secondary/tertiary/hindered/cyclic | knowledge base, not a paper value unless stated |
| `salt_form` | parent/salt | default parent |
| `mw` | molecular weight | whitelist/PubChem |
| `purchasable`, `status` | project metadata | default |

### `source`

| Field | Meaning | Source in reading |
|---|---|---|
| `doi` | DOI | paper first page/metadata |
| `url` | article URL | optional |
| `title` | title | paper, verbatim |
| `authors` | authors | paper, verbatim |
| `year` | publication year | paper |
| `journal` | journal | paper |
| `pdf_path` | local PDF path | manifest |
| `pdf_hash` | SHA-256 of PDF | compute |
| `source_type` | paper/other | default paper |

### `source_location`

| Field | Meaning | Source in reading |
|---|---|---|
| `source_id` | FK to source | assigned |
| `loc_type` | table/figure/text/equation | paper |
| `loc_label` | page/table/figure | paper |
| `loc_detail` | compact row identity (auto) | generated by importer |
| `excerpt_path` | path to an excerpt file | optional; see gap below |
| `extraction_method` | manual/LLM/pdfplumber | record |

**Known gap:** `import_jsonl.py` reads `source.excerpt_path`, not `source.excerpt`. The excerpt text in `raw_agent.jsonl` is not stored in `source_location`. The raw snapshot is the primary evidence. If DB-level excerpt traceability is required, provide an `excerpt_path` file and list the extension in `schema_extension_recommendations.md`.

### Other tables

`method`, `qc_record`, `candidate`, `failure_log`, `audit_log` exist. The current import script does not populate `method` from JSONL; `test.method_id` can be supplied only if a method row already exists. Record apparatus/method details in the report and propose an extension if method-level traceability is required.

```json
    "excerpt_path": null

    "co2_partial_kPa": null, "total_pressure_kPa": null,
    "gas_flow": null, "liquid_volume": null, "gas_liquid_ratio": null,

```

## Required fields for L2

- `temperature_K`
- `co2_vol_pct`
- `initial_loading`
- closed recipe (`wt_a + wt_b + water = 100 ± 0.1`)
- snapshot path/hash
- explicit location and excerpt

If any is missing, `validate.py` puts the record in `valid_incomplete` (L3) or rejects it, depending on the issue.

## Metric enum

Use exactly one of:

`equilibrium_loading`, `cyclic_capacity`, `cyclic_capacity_volumetric`, `regeneration_energy`, `regeneration_heat`, `regeneration_efficiency`, `initial_absorption_rate`, `initial_desorption_rate`, `absorption_rate_volumetric`, `absorption_amount_volumetric`, `co2_removal_efficiency`, `cost_per_tonne_co2`, `iron_solubility`, `pka`, `model_prediction_deviation`, `annual_energy_consumption_reduction`, `aard_equilibrium_co2_partial_pressure`.

If a value does not fit, keep it in the report and propose an extension; do not force a wrong enum.

## Simulation records

- `test_origin="simulation"`.
- `qc_level="L3"`, `qc_reason` starts with `simulation_data`.
- `performance.is_derived=1`.
- Total amine may exceed 50 wt%; mass balance and binary identity still apply.
- Never enters `gold_standard_L2`.

## Validation and import

```powershell
.\.venv\Scripts\python.exe scripts\validate.py --input extractions\<batch>\raw_agent.jsonl --outdir extractions\<batch>
.\.venv\Scripts\python.exe scripts\import_jsonl.py --input extractions\<batch>\valid.jsonl --config config.yaml --batch-id <batch>
```

- `valid.jsonl` → main DB.
- `valid_incomplete.jsonl` → main DB as L3, with audit log.
- `rejected.jsonl` → never imported.
- `postcheck.py --batch <batch>` must pass all seven checks.
