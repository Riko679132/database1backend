# Phase 3 — 27-Point VLE Root Cause and Fix

## Paper and target

- DOI: `10.1021/je00005a025` (Shen & Li, *J. Chem. Eng. Data* 1992, 37, 96–100).
- Target: 27 points = the **40 °C low-pressure column group** of Tables II–V:
  - Table II, 30 wt% MDEA: 6 points
  - Table III, 12 wt% MEA + 18 wt% MDEA: 7 points
  - Table IV, 24 wt% MEA + 6 wt% MDEA: 7 points
  - Table V, 30 wt% MEA: 7 points
- Methods: low-pressure apparatus at ~180 kPa total pressure, ~0.5 L solution, fresh solution.

## Point accounting (before vs after)

|---|---:|---:|
| Table II 40 °C low-P | 6 (L3) | 6 (L2) |
| Table III 40 °C low-P | 0 | 7 (L2) |
| Table IV 40 °C low-P | 0 | 7 (L2) |

| Extra LLM MDEA >180 kPa points | 6 | 7 (kept as L3) |

**Important correction:** the original report said 12/27. That was an evaluator artifact: the LLM extracted six >180 kPa MDEA points and the evaluator allowed them to match Table V MEA points because amine identity was only a score penalty. After requiring amine identity, the true before coverage was **6/27**, not 12/27.

The detailed per-point checklist is `evaluation/reports/vle_27_point_checklist.md` (generated by `evaluation/build_vle_checklist.py`).

## Where the 21 missing points were lost

| Chain stage | Finding |
|---|---|
| 1. PDF pages | Tables II–V are four side-by-side column groups (40/80/100 °C), split across pages 3–4. |
| 2. Plain text | `pdf_to_text` interleaves the column groups; the Table II footnote ("p, partial pressure…") appears in the middle of the data rows. |
| 3. Table structure | No per-group header/column assignment; one header row defines two t/p/loading groups. |
| 4. LLM input | Table-grid context was present, but the LLM still extracted only Table II's 40 °C group. |
| 5. LLM output | 12 MDEA 30 wt% points: 6 target low-P + 6 high-P; Tables III/IV/V absent. |
| 6. Final records | Six target MDEA points were L3 because `co2_vol_pct`/`initial_loading` were missing; the other 21 points did not exist. |
| 7. Evaluator | Six high-P MDEA points were falsely matched to Table V MEA points, producing the "12/27" figure. |

## Fix: deterministic column-group parser

Code: `server/vle_table_parser.py`.

1. Read each page with `pdfplumber.extract_words`.
2. Cluster words into rows by `round(top/4)`.
3. Detect header rows containing `t/…`, `p/kPa`, `loading`.
4. For each `p/kPa` header, find the nearest left `t` column and nearest right `loading` column; this defines one column group.
5. Assign every numeric token to its nearest t/p/loading column by x-coordinate (not independent tolerance windows).
6. Carry the group's temperature down rows; skip rows without p/loading.
7. Do not terminate at an interleaved footnote; only the next header ends the group.
8. Parse the table caption/recipe from the preceding rows (amine tokens + wt% values).
9. Select the paper profile: 40 °C and P_CO2 ≤ 180 kPa; total pressure 180 kPa; liquid volume 0.5 L; initial loading 0.
10. Convert points to raw_agent records with table/page/row evidence, then normalize/verify/snapshot.

The profile is intentionally paper-specific (`PROFILES["10.1021/je00005a025"]`); method constants are not applied to other papers.

## Integration

`server/tasks.py` runs the parser after LLM normalization when a profile exists:

- deterministic records are normalized and machine-verified;
- LLM duplicate rows are dropped by
  `(DOI, amine_a, amine_b, wt_a, wt_b, T, P_CO2, performance)`;
- parser rows are preferred; non-duplicate LLM high-pressure rows remain L3;
- snapshot `table_grid.vle_parser` records table counts, recipes and selected points.

## Result

- Parser counts: 4 tables, 181 total detected points across all temperature groups, **27 selected 40 °C low-P points**.
- `validate.py`: 27 valid L2 + 7 incomplete L3.
- VLE regression: 27/27 matched, 284/284 expected fields within tolerance.
- Extra high-pressure MDEA points remain L3 and are not counted as matched.

## Remaining limitations

- The parser's profile is paper-specific; another multi-column VLE paper needs its own target-temperature/total-pressure profile.
- The parser detects repeated t/p/loading groups, but not arbitrary multi-level headers or merged cells with different column semantics.
- The 181 all-temperature points are parsed but only the 27 target points are converted; other temperatures may be extracted later with their own total-pressure conditions.
- No data were fabricated and no original values were overwritten.
